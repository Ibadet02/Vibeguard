The user is karma-farming / reputation-building on Reddit and Indie Hackers to market VibeGuard (see memory). They will paste one of:
- A **list of post titles** (from a subreddit or an IH group)
- A **single post** (with or without its comments), as text or screenshot

# Before drafting
Read these memory files for full context (paths relative to the memory dir at `~/.claude/projects/-home-ismayilov-i-Desktop-projects-NEW-saas/memory/`):
- `writing-style.md` — the user's exact comment voice (mandatory for every draft)
- `reddit-upvote-patterns.md` — what earns upvotes; karma play vs reputation play
- `vibeguard-distribution.md` — target subs and the 9:1 helpful-to-promo rule
- `vibeguard-project.md` — what VibeGuard is, for spotting relevant threads

# If given a list of titles
Rank the 1-3 best posts to comment on. Criteria:
- **Freshness first** — minutes/hours old beats days old; skip anything over ~2 days unless it's very active, and always skip years-old pinned posts
- **Low comment count** = visibility for an early comment; huge threads only if the user can say something distinct
- **Relevance to VibeGuard's audience** (AI-built apps, security, Lovable/Bolt/Cursor/v0/Replit builders) ranks above generic founder content
- Flag any post that is a competitor or potential partner — that's strategic value beyond karma
Say briefly why each pick, and which one to hit first.

# If given a single post
1. Give a 2-3 sentence plain summary of what the OP is saying (the user often asks for this).
2. State the play: **karma play** (voice what the room is thinking, short and blunt, pointed question) or **reputation play** (security/founder threads where insight builds credibility; usually no pitch — 9:1 rule).
3. Draft ONE comment in the user's voice per `writing-style.md`. Lead short — the user almost always asks to shorten, so start tight. Match the room's mood (skeptical thread → skeptical comment; celebration → warm + one sharp observation).
4. If it's a judgment call (softer vs sharper, with vs without a VibeGuard mention), offer the one alternative briefly.

# Hard rules
- Never suggest automating the actual posting — human posts, always.
- Never fabricate facts/stats in comments; hedge with "I think" where uncertain.
- When the user pastes back their edited version of a draft, diff it against the draft, extract style lessons, and update `writing-style.md` (and `reddit-upvote-patterns.md` for top-comment examples they share).
